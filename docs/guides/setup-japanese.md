# LaravelPress を日本語でセットアップする

このガイドでは、Docker 上の LaravelPress を **日本語 UI・日本語サイト言語** で初期セットアップする手順を説明します。

---

## 1. 起動する

```bash
docker compose up -d --build
docker compose port app 8000
```

表示されたポートでブラウザを開きます（例: `http://127.0.0.1:32772`）。

未インストールの場合は自動的に `/setup`（セットアップウィザード）へ進みます。

---

## 2. セットアップ画面を日本語にする

ウィザード上部の **言語切り替え** で **日本語** を選びます。

以降のセットアップ画面のラベル・説明が日本語になります。

---

## 3. 要件チェック → データベース

1. **はじめる / 要件** を進める  
2. **データベース** 画面で、Docker Compose 用の値を入力する:

| 項目 | 値 |
|------|-----|
| Host | `postgres` |
| Port | `5432` |
| Database | `cms` |
| Username | `cms` |
| Password | `cms_secret` |

3. 接続テストに成功したら保存する

---

## 4. サイト情報で「日本語」を選ぶ（重要）

**ウェブサイト** 画面で次を設定します。

- **サイト名** … 例: `青山キャピタル`
- **サイト言語** … **Japanese (`ja`)** を選択
- **タイムゾーン** … 例: `Asia/Tokyo`

ここで `ja` を選ぶと、サイト設定・管理者の初期ロケール・`APP_LOCALE` が日本語寄りになります。

---

## 5. 管理者アカウントを作る

- 表示名 / メールアドレス
- パスワード（**12文字以上**、大文字・小文字・数字・記号を含む）

サイト言語が `ja` の場合、管理者ユーザーの `locale` も日本語になります。

---

## 6. 外観を選んでインストール

1. **外観** でテーマ / UI フレームワークを選択（後から変更可能）
2. **インストール** を実行する
3. 完了後、`/admin` でログインする

管理画面右上の言語が **日本語** になっているか確認します。違う場合は **日本語** に切り替えてください。

---

## 7. （任意）デモを入れる / 管理画面ガイド

### 管理画面から（推奨）

1. `/admin/help/setup-guide`（ナビ: **セットアップガイド**）を開く  
2. **ダミーデータをインストール** または **青山カードサイトをインストール** を押す  
3. 同じページの「使い方」から固定ページ・投稿・メディアなどへジャンプ

同じボタンは **設定 → 一般 / UI** にもあります。

### CLI

```bash
docker compose exec -T app php artisan laravelpress:demo-seed --fresh
docker compose exec -T app php artisan laravelpress:seed-aoyama --fresh
```

確認ポイント:

- **公開側** … `/` や `/card`（青山デモ時）が日本語コンテンツになっている  
- **管理側** … メニュー・ボタンが日本語になっている  
- **ページ編集** … シード済み HTML は **カスタムHTML** ブロック

### あとから言語を変える場合

- 管理画面右上の **言語切り替え**（セッション）
- **設定 → 一般** のサイト言語
- ユーザープロフィールのロケール（対応している場合）
